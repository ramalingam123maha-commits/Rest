# Rest

A minimal Java repository containing a single source file, `Addition.java`.

## Project Summary

This project currently serves as a basic Java starter example. It includes one class named `Addition` with a `main` method and a placeholder comment for an addition program.

At the moment, the program does not perform any calculation or print output.

## Repository Contents

### `Addition.java`
Java source file that defines the `Addition` class and contains the program entry point:

- Declares `public class Addition`
- Includes `public static void main(String[] args)`
- Marks the intended purpose with a placeholder comment: `// Addition program`

### `.git/`
Git metadata directory used for version control.

## Requirements

- Java Development Kit (JDK)
- Command-line access to `javac` and `java`

## Build Instructions

Compile the Java source file from the repository root:

```bash
javac Addition.java
```

## Run Instructions

Run the compiled program:

```bash
java Addition
```
