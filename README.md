# EduTrack - Student Management Dashboard

A comprehensive, responsive Student Management Dashboard built with vanilla modern HTML5, CSS3, and JavaScript.

## Features
- **Student Registration & Directory:** Register new students, update profiles, filter by department and status, search with live queries.
- **Academic Progress Tracking:** Record and calculate credits, weighted GPA/CGPA across grading scales (A+ through F), track attendance rates, and visualize academic standing brackets.
- **Enrollment Management:** Manage course enrollments across academic terms, monitor course capacity and department offerings, unenroll students when needed.
- **Performance Report Generator:** Generate certified printable academic transcripts with semester breakdown, cumulative GPA, quality points, and export options (JSON / CSV).
- **Persistent Storage:** Synchronized with browser LocalStorage for offline persistence.
